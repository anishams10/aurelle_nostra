# AMIRA

AMIRA is a luxury fashion and lifestyle website designed with an elegant, modern aesthetic. The project focuses on creating a visually appealing browsing experience with refined typography, stylish layouts, and interactive elements.

## 🔗 Live Demo

[View Aurelle Nostra](https://anishams10.github.io/aurelle_nostra/index.html)

## ✨ Features

- Elegant and modern website design
- Responsive layout for different screen sizes
- Interactive navigation and UI elements
- Stylish typography and image layouts
- Smooth hover effects and transitions
- Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/anishams10/aurelle_nostra.git
   ```

2. Open the project folder:

   ```bash
   cd aurelle_nostra
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## 🎯 Project Purpose

This project was created to practice frontend development, responsive web design, Tailwind CSS styling, and JavaScript interactions while building a polished website experience.
